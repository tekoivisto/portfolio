In this project, I created a website for my engineering project portfolio using HTML and CSS. A screenshot of the website is shown in Figure 2.2. In fact, you are looking at the project right now!

Even though I have no prior experience with web development, getting an initial portfolio template site up and running took only about 15 minutes using Claude and GitHub Pages. It never ceases to amaze me how good the LLMs are these days. This website’s layout and functionality are heavily vibecoded, but the actual text, figures, and videos are created by me. In the other projects made during the AI era, I have used AI to help with debugging and to add individual, easily verifiable bits of code, but the projects are actually made by me. AI is great when things work. When they don't, the more control you have given it, the more screwed you are.
