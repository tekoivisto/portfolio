2.1Soft-Body Tetris Simulation

May 2025
Julia, Makie

In this project, I made a soft-body Tetris game from scratch. My main goal for this project was to start learning the Julia programming language, since I wanted to learn a language that is faster than Python but still high-level and easy to use. A demo of the game is shown in Video 2.1, where I beat my previous highscore. The game turned out to be quite fun and satisfying to play.
